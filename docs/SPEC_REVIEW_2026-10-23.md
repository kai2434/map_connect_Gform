- 該当：`src/styles/main.css:474-480`、`520-525`、`669-675`

### 2. [P1] GitHub ActionsのUbuntu環境で必須のブラウザテストを起動できない

### 4. [P2] 地図タイルが全件失敗してもエラーと再読み込み案内が消える

- 再現：ブラウザはオンライン状態のまま、地理院タイルへの要求だけをすべて失敗させて再読み込みする。

- 既存テストの限界：オフラインイベントの後で再読み込みボタンを押すとバナーが閉じることだけを確認しており、実際のタイル失敗が続く場合を確認していない。

- 該当：`tests/app.test.mjs:104-116`、`tests/e2e-browser.test.mjs:184-186`、`232-233` など。
